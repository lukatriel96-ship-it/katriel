# Katriel & Freitas Advogados — Landing Page BPC/LOAS

Site estático em HTML, CSS e JavaScript, pronto para GitHub e Vercel.

## Estrutura

- `index.html` — conteúdo e SEO
- `styles.css` — layout responsivo
- `script.js` — menu mobile, FAQ, animações e formulário para WhatsApp
- `favicon.svg` — ícone do site
- `vercel.json` — headers básicos de segurança para Vercel
- `robots.txt` — instruções para buscadores

## Publicar no GitHub

1. Crie um repositório novo.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Faça commit e push para a branch `main`.

## Publicar na Vercel

1. Entre na Vercel e escolha **Add New > Project**.
2. Importe o repositório do GitHub.
3. Framework Preset: **Other**.
4. Não é necessário comando de build.
5. Output Directory: deixe em branco.
6. Clique em **Deploy**.

## Antes de publicar

- Se houver domínio próprio, adicione `og:url`, `canonical` e atualize `robots.txt`.
- Se o escritório tiver endereço, OAB, e-mail ou redes sociais, inclua essas informações no rodapé e nos dados estruturados.
- A imagem principal utiliza uma foto gratuita do Unsplash (Tingey Injury Law Firm): https://unsplash.com/photos/yCdPU73kGSc
- Revise o conteúdo jurídico antes da publicação para adequação ao posicionamento e às regras de publicidade profissional aplicáveis.
